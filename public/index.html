              5
              Capas de validación
            
    
            
      
              
    • Format check — longitud, caracteres permitidos, Unicode legítimo
      • 
              
    • Normalización — NFD, leet (4→a, 0→o…), confusables cirílico/griego, fonético
      • 
              
    • Listas estáticas — profanity, slurs, jokes, exact-only, scunthorpe whitelist
      • 
              
    • Aho-Corasick — detección multi-patrón con tolerancia a separadores
      • 
              
    • IA (Claude / GPT / Gemini) — fallback con voto de confianza para casos ambiguos
      • 
            
    
          
    

          
    
            
    
              ∞
              Trampas que detecta
            
    
            
      
              
    • Profanity directa en cualquier idioma
      • 
              
    • Nombres-broma fonéticos (Aitor Tilla, Helio Cóptero, Mike Hunt…)
      • 
              
    • Slurs racistas, homófobos, religiosos
      • 
              
    • Apología nazi / fascista / terrorista
      • 
              
    • Figuras históricas controvertidas (dictadores, criminales)
      • 
              
    • Substituciones leet (pu7@, F.U.C.K, p_u_t_a)
      • 
              
    • Reverso (atup → puta)
      • 
              
    • Caracteres confusables (а cirílico vs a latino)
      • 
              
    • Espacios y separadores artificiales
      • 
              
    • Nombres del Real Madrid usados de forma ofensiva
      •
