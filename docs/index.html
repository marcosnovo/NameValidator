HALO Name Validator

Comprobador de nombres aptos para mostrarse en el HALO del Santiago Bernabéu. Detecta lenguaje soez, insultos discriminatorios, nombres-broma, trampas fonéticas y suplantación de jugadores rivales en ES · EN · FR.

Versión GitHub Pages: se ejecuta enteramente en tu navegador. Las listas estáticas (~700 nombres-broma + ~400 términos vulgares + jugadores rivales) están siempre activas y son gratis. La capa semántica (Claude Opus 4.7) se activa configurando un proxy de backend (recomendado) o pegando tu clave de API directa (sólo para demostraciones).

Pulsa Intro para validar. Prueba variantes sutiles (espacios extra, sustituciones leet, mayúsculas raras, tildes): el sistema las normaliza antes de evaluar.
